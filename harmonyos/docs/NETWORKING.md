# 网络策略

- 连接超时统一为 15 秒；B站读取超时 30 秒；非流式 LLM 单次生成读取超时 5 分钟。
  较长的有界等待用于容纳思考模型的忠实详细输出，不代表自动重试。
- 每个业务操作只拥有一个活动请求，页面离开或用户取消时销毁请求并返回统一取消错误。
- B站视频、字幕等 GET 是幂等读取。网络传输失败后允许操作层最多再尝试一次；鉴权、风控、无字幕和解析错误不重试。
- LLM 生成是可能计费的 POST。不得在无法确认服务端是否已接收时盲目自动重试；失败后由用户明确触发重试。
- 单个响应上限为 8 MiB；不在日志中输出 Cookie、API Key、字幕正文或模型响应。
- 429、5xx、超时、取消与业务错误由 data 层映射为稳定的应用错误码，页面只负责展示用户文案。
