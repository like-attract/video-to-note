# VideoToNo HarmonyOS

VideoToNo HarmonyOS 将 B 站已有字幕整理为可保存、检索和分享的时间轴笔记。它与桌面版共享产品语言，但不依赖桌面运行时。

## Language

**B站会话**:
用户通过 B 站二维码登录后，在设备本地建立的授权状态；它可能失效，但不代表用户在 VideoToNo 中注册了账号。
_Avoid_: VideoToNo 账号、用户账号

**视频资料**:
由一个 B 站视频及其分 P、标题、作者和可用字幕共同构成的笔记输入。
_Avoid_: 本地视频、下载任务

**字幕轨道**:
B 站为某个分 P 提供的一种语言或生成方式的字幕集合，可以是 AI 字幕或人工字幕。
_Avoid_: 转录模型、Whisper 结果

**生成任务**:
把一份视频资料交给用户选择的模型服务商并产出视频笔记的可恢复过程。
_Avoid_: 后端任务、云端任务

**视频笔记**:
由模型根据字幕生成、带来源和时间点的 Markdown 内容，是应用长期保存和管理的核心成果。
_Avoid_: 摘要结果、临时输出

**模型配置**:
用户选择的模型服务商、模型、思考强度、笔记风格和可选的本地凭据保存策略。
_Avoid_: 运营商配置、系统模型

**华为生态分享**:
用户通过 HarmonyOS 系统分享面板把视频笔记交给华为笔记、中转站或其他目标应用的操作。
_Avoid_: 自动写入华为笔记、笔记同步
